Enviar imagens em massa

Seleciona várias imagens de uma só vez. O ID é lido do início do nome do ficheiro (por exemplo, 0000-einstein.jpg corresponde ao desafio 0).

Podes selecionar várias imagens ou um ZIP. Dentro do ZIP, cada imagem deve começar pelo ID do desafio, por exemplo 0000-einstein.jpg, 0001-lisboa.jpg.

Após o envio, a imagem fica guardada no Supabase e é associada automaticamente à solução com o mesmo ID.
