# Arquivo de propostas históricas

Esta pasta conserva propostas, rascunhos e fixtures históricos do desenvolvimento do ATINA.

- **Não são migrations ativas.** As alterações de base de dados aplicáveis estão em `supabase/migrations/`.
- Os ficheiros foram preservados sem alterações de conteúdo; apenas a localização mudou.
- Alguns SQL podem estar desatualizados ou duplicar versões que entretanto foram integradas. Não executar diretamente em produção.
- Para perceber o estado atual, consultar `README.md` na raiz e `SECURITY-DESIGN.md`.

A pasta existe para manter o histórico útil sem misturar propostas antigas com o fluxo ativo de migrations.
