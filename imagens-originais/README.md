# Imagens originais ATINA

Esta pasta destina-se exclusivamente a guardar cópias originais das imagens, sem marca de água, logótipo, recorte, redimensionamento, compressão adicional ou qualquer outra alteração.

- Os originais devem manter o nome baseado no ID real do desafio.
- As versões editadas ou com o logótipo oficial devem ser guardadas noutra pasta e nunca substituir estes ficheiros.
- A página Gestão de imagens permite descarregar cada original individualmente ou exportar os originais selecionados/visíveis num ZIP, mantendo os bytes do ficheiro de origem.

Não adicionar imagens sem confirmar o ID e a correspondência com a solução ATINA.
